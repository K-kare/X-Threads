X-Threads 🧵
A Twitter clone built with Django, focusing on user authentication, posting threads, following users, and more.

🚀 Features
  . User registration, login, and logout
  . Create, edit, and delete Meeps (posts)
  . Follow and unfollow other users
  . User profile with list of Meeps and followers

🛠️ Built With
. Python
. Django (Backend Framework)
. HTML/CSS & Bootstrap.
